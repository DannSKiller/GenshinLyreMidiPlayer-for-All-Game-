
# Midi Player

A lightweight MIDI player with keyboard automation support. Play MIDI files and send keystrokes to any active window.

## Usage

1. Launch `GenshinLyreMidiPlayer.WPF.exe`
2. Open a MIDI file via the playlist
3. Select your keyboard layout and instrument in Settings
